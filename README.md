# Games — PWA

ブラウザから遊べるHTMLゲーム5本を、インストール可能なPWAとしてまとめています。元のゲームHTMLは維持しています。

## アクセス
GitHub Pagesで **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save** を設定します（未設定の場合）。

公開URL: https://miumiu73my-beep.github.io/Games/

iPhone・iPad: 上記URLを **Safari** で開く → 共有 → **ホーム画面に追加**。初回はオンラインで全ゲームを読み込み、キャッシュ完了後はオフラインで利用できます。

## 技術
- フレームワーク・ビルド不要（静的HTML / manifest / Service Worker）
- 同じフォルダをGitHub Pagesに公開（サブパス `/Games/` 対応）
- オフライン: Service WorkerがゲームHTMLを初回にキャッシュ
- 更新を確実に反映したい場合は `sw.js` の `CACHE` を新しいバージョンに変更
- セーブ: 各ゲーム既存のブラウザ保存方式を維持。Safari・ホーム画面アプリ・別端末でデータが共有されるとは限りません。
- 端末内データが必要な場合はブラウザのサイトデータを消さないでください。

## 原本
既存のゲームHTMLは原本です。オリジナルの保存処理を保つため、PWA化のためにゲーム内部のロジックは変更していません。

## 2026-11 PWA整備
- 各ゲームを直接開いてもService Workerを登録できるようにしました。
- ゲーム画面右下の「ゲーム一覧」からPWA内で本棚へ戻れます（ゲーム本体のロジックは未変更）。
- 5本すべてを初回インストール時にキャッシュし、オンライン復帰時は新しい画面を取得します。
- 静的ファイルの整合性はGitHub Actions（`PWA static checks`）で検査します。ローカルなら `node scripts/check-pwa.mjs` でも検査できます。
- GitHub Pagesが無効な場合は上記のSettings → Pagesで有効化してください。公開設定の変更はこのコミットには含まれていません。
